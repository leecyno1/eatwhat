# EatWhat 2.0 - 开发计划 (Roadmap)

## 📅 总体时间表
- **Phase 1 (基础架构 & 视觉)**: 2025.11.30 - 2025.12.05
- **Phase 2 (AI 增强)**: 2025.12.06 - 2025.12.10
- **Phase 3 (执行路径)**: 2025.12.11 - 2025.12.15
- **Phase 4 (闭环优化)**: 2025.12.16 - 2025.12.20

## 🛠️ 详细任务清单

### Phase 1: 基础架构与视觉重构 (Priority: High)
- [ ] **数据库构建**
  - [x] 定义 `Unified Recipe Schema` (已完成文档)。
  - [ ] 创建 `TagRepository` 和 `RecipeRepository` 的 V2 版本。
  - [ ] 编写脚本将 `HowToCook` 数据转换为新 Schema 格式。
  - [ ] 扩充标签库至 100+ 个，并为每个标签分配 `VisualConfig`。

- [ ] **视觉实体系统 (Visual Entity System)**
  - [ ] 设计 `VisualEntity` 类，支持形状、颜色、图标、粒子特效配置。
  - [ ] 重构 `BubbleBody`，使其能根据 `VisualConfig` 渲染不同效果。
  - [ ] 实现 5 类核心视觉模板：
    - `SpicyEntity` (辣椒形状 + 红色 + 蒸汽)。
    - `MeatEntity` (肉块形状 + 纹理)。
    - `VeggieEntity` (叶子形状 + 绿色)。
    - `LiquidEntity` (水滴形状 + 流动感)。
    - `MagicEntity` (占卜/元数据 + 星光特效)。

- [ ] **用户偏好存储**
  - [ ] 引入 `Hive` 或 `SharedPreferences`。
  - [ ] 实现 `UserPreferenceService`，记录标签点击次数和权重。

### Phase 2: AI 深度集成 (Priority: Medium)
- [ ] **AI 服务升级**
  - [ ] 升级 `AiService`，支持多模态输出（文本 + 图片生成 Prompt）。
  - [ ] 接入图片生成 API (需调研可用免费/低成本 API，或使用 Mock)。
  - [ ] 实现 `NutritionAnalyzer`，让 AI 对生成的菜谱进行营养打分。

- [ ] **搭配推荐系统**
  - [ ] 在 `DecisionPage` 增加 "Upsell Bubbles" 逻辑（推荐饮料/配菜）。

### Phase 3: 执行路径实现 (Priority: Medium)
- [ ] **自制路径 (Home Cooking)**
  - [ ] 升级 `RecipeDetailPage`，展示 AI 生成的营养分析。
  - [ ] 增加 "烹饪模式" (大字号、计时器)。

- [ ] **到店/外卖路径 (Dine-in/Delivery)**
  - [ ] 创建 `RestaurantPage` 和 `DeliveryPage`。
  - [ ] 模拟 API 数据返回（附近餐厅列表）。
  - [ ] 集成 `url_launcher` 打开外部地图或外卖 App。

### Phase 4: 收藏与闭环 (Priority: Low)
- [ ] **收藏系统**
  - [ ] 实现 "收藏" 按钮（在气泡、结果页、详情页）。
  - [ ] 创建 "我的收藏" 页面。
  - [ ] 将收藏数据反馈给 `BubbleDataManager`，提高相关气泡出现率。

## 🚀 启动任务
当前首要任务是 **Phase 1 - 数据库构建**。我们需要先建立坚实的数据基础。
