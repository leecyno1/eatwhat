# 美团外卖开放平台注册手册（P1-2）

> 阻塞点：`.env` 里的 `MEITUAN_OPEN_APP_ID=2617865019071017` 未在美团 OAuth 系统注册，
> 授权页预览接口返回 10005、页面静默白屏。这是外卖链路的唯一外部硬阻塞，
> 必须线下完成注册后，代码侧即刻可用（链路已全部实现）。

## 一、去哪注册

[美团开放平台](https://open.meituan.com) → 开发者入驻 → 创建「外卖/配送」类应用。

**资质要求**：外卖应用需企业主体——营业执照 + 对公账户验证。个人开发者无法注册此类应用；
若当前无企业主体，此条路线需要先解决主体问题。

## 二、创建应用时要填的技术值

| 字段 | 填什么 |
|---|---|
| 应用类型 | 外卖（外卖开放平台，API 基座 `https://openapi.waimai.meituan.com`） |
| 授权回调地址 | `https://<你的公网域名>/oauth/callback` —— 由 delivery adapter 提供（路由 `GET /oauth/callback`），**必须 https**，回调经 nginx/网关转到 adapter |
| 授权范围 | `scope=all`（空值会让授权页只渲染 logo、授权按钮不出现——已踩过） |

## 三、拿回什么、配到哪

注册通过后拿回 `app_id` 与 `app_secret`，更新 `.env`：

```
MEITUAN_OPEN_APP_ID=<新 app_id>
MEITUAN_OPEN_APP_SECRET=<新 app_secret>
MEITUAN_OAUTH_REDIRECT_URL=https://<你的公网域名>/oauth/callback   # 当前未配，必须补
MEITUAN_OPEN_ORDER_ENABLED=true                                   # 打开真实下单
```

> 注意：当前 `MEITUAN_OAUTH_REDIRECT_URL` 在 `.env` 里**缺失**——不补的话即使 app_id
> 注册成功，授权链接里的 redirect_uri 也是空的。

## 四、注册后验证（三层健康检查）

1. 代理存活：`GET /health` → `meituan: true`
2. OAuth 状态：`GET /api/v1/delivery/oauth/status` → 走完一次授权后 `connected: true`
3. 真实门店搜索：结果页「外卖到家」走完全程 → 返回真实商家列表（不再是 `meituan_oauth_required`）

## 五、排坑指南（历史诊断沉淀）

- **白屏先看 preview 接口返回码**：`code 10005` = app_id 未注册；`code 100` = 浏览器无美团登录态（换个已登录美团的浏览器）
- **别用 QQ 内置浏览器授权**：X5 内核拦截 https→http 跳转，回调到不了服务端
- **授权链接的 state 一次性、30 分钟过期**：白屏/过期就重新生成链接
- **本地验收**：模拟器跑 App + 用 Chrome/Safari 完成授权；自动化浏览器（browser-use MCP）没有你的美团登录态，不能替代真人操作
