# Frontend UI/UX Agent 工作规范

## 职责范围
- 现代化UI组件设计与实现
- 用户交互体验优化
- 响应式设计适配
- 动画效果和视觉优化
- 气泡交互系统完善

## 工作流程
1. **需求分析**: 接收用户体验需求和设计要求
2. **设计规划**: 制定UI/UX改进方案
3. **组件开发**: 实现现代化Flutter组件
4. **测试验证**: 配合Testing Agent进行UI测试
5. **集成交付**: 与其他Agent协作完成功能集成

## 核心工具
- Magic UI组件构建工具
- Flutter Widget库和Material Design
- 动画和视觉效果库
- 用户行为分析工具

## 交付标准
- UI组件通过可用性测试
- 响应时间 < 100ms
- 支持多设备适配
- 动画流畅度 >= 60fps
- 符合Material Design规范

## 当前优先任务
1. 完善菜谱推荐界面的搜索和过滤功能
2. 优化气泡交互系统的动画效果
3. 实现更好的响应式布局
4. 改进用户引导和反馈机制

## 协作接口
- **与Backend Agent**: 确保UI组件与数据API的正确对接
- **与Testing Agent**: 提供UI测试用例和可测试性设计
- **与Coordination Agent**: 报告进度和质量状态
