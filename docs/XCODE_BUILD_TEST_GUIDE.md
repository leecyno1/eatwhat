# 📱 Xcode构建和测试指南 - 菜谱项目

## 🚀 第一步：打开Xcode项目

### 1. 打开Xcode项目
```bash
cd /Users/lichengyin/Desktop/Projects/eatwhat
open ios/Runner.xcworkspace
```

**重要：** 必须打开 `.xcworkspace` 文件，不是 `.xcodeproj` 文件！

## ⚙️ 第二步：配置Xcode项目

### 1. 项目基本设置
在Xcode中：
1. 点击左侧的 **"Runner"** 项目
2. 选择 **"Runner"** target
3. 在 **"General"** 标签页中：
   - **Display Name**: EatWhat 或 吃什么
   - **Bundle Identifier**: 改为唯一标识符，如 `com.yourname.eatwhat`
   - **Version**: 1.0.0
   - **Build**: 1
   - **iOS Deployment Target**: 设置为 **11.0** 或更高

### 2. 代码签名配置
在 **"Signing & Capabilities"** 标签页中：
1. 勾选 **"Automatically manage signing"**
2. 选择您的 **Development Team**
3. 确保 **Bundle Identifier** 唯一且可用

### 3. 构建设置检查
在 **"Build Settings"** 标签页中：
- 搜索 **"iOS Deployment Target"**
- 确保所有target都设置为 **11.0** 或更高
- 搜索 **"Valid Architectures"**
- 确保包含 **arm64** 和 **x86_64**

## 📱 第三步：选择目标设备

### 1. 选择设备
在Xcode顶部的设备选择器中：
- **真机测试**: 选择连接的iPhone/iPad
- **模拟器测试**: 选择iOS模拟器（推荐iPhone 14或更新）

### 2. 如果使用真机
确保：
- iPhone已连接到Mac
- iPhone已解锁并信任此电脑
- 开发者账号已配置

## 🔧 第四步：执行构建

### 1. 清理项目
- 菜单栏 → **Product** → **Clean Build Folder** (⇧⌘K)

### 2. 构建项目
- 菜单栏 → **Product** → **Build** (⌘B)
- 或点击左上角的 **▶️ 播放按钮**

### 3. 观察构建过程
在Xcode底部的状态栏中查看构建进度：
- **"Building..."** - 正在构建
- **"Build Succeeded"** - 构建成功 ✅
- **"Build Failed"** - 构建失败 ❌

## 🔍 第五步：处理构建错误（如有）

### 常见错误和解决方案

#### 错误1: Code Signing Error
```
Code signing is required for product type 'Application'
```
**解决方案:**
1. 确保选择了Development Team
2. 检查Bundle Identifier是否唯一
3. 确保iOS设备已信任

#### 错误2: iOS Deployment Target
```
iOS deployment target is set to 8.0
```
**解决方案:**
1. 将所有target的iOS Deployment Target设置为11.0+
2. 检查Pods项目中的target设置

#### 错误3: Missing Frameworks
```
Framework not found
```
**解决方案:**
1. 确保执行了 `pod install`
2. 检查是否打开了正确的 `.xcworkspace` 文件
