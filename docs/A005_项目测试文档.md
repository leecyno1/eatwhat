#### 2. 推荐引擎测试
```dart
// test/unit/recommendation_engine_test.dart
import 'package:flutter_test/flutter_test.dart';
import 'package:mockito/mockito.dart';
import 'package:eatwhat/core/services/recommendation_engine.dart';

void main() {
  group('Recommendation Engine Tests', () {
    late RecommendationEngine engine;
    late MockFoodService mockFoodService;
    
    setUp(() {
      mockFoodService = MockFoodService();
      engine = BasicRecommendationEngine(mockFoodService);
    });
    
    test('should return recommendations based on user preference', () async {
      // Arrange
      final preference = UserPreference(
        likedTastes: ['甜味', '咸味'],
        dislikedTastes: ['苦味'],
        priceRange: PriceRange(min: 10, max: 50),
      );
      
      final mockFoods = [
        Food(id: '1', name: '甜品', tags: ['甜味']),
        Food(id: '2', name: '咸菜', tags: ['咸味']),
        Food(id: '3', name: '苦瓜', tags: ['苦味']),
      ];
      
      when(mockFoodService.getAllFoods()).thenReturn(mockFoods);
      
      // Act
      final result = await engine.recommend(preference);
      
      // Assert
      expect(result.length, 2);
      expect(result.any((food) => food.tags.contains('苦味')), false);
    });
  });
}
```

// test/integration/app_flow_test.dart
import 'package:flutter_driver/flutter_driver.dart';
import 'package:test/test.dart';

void main() {
  group('App Integration Tests', () {
    FlutterDriver driver;
    
    setUpAll(() async {
      driver = await FlutterDriver.connect();
    });
    
    tearDownAll(() async {
      if (driver != null) {
        driver.close();
      }

      // 启动应用
      await driver.waitFor(find.byType('HomeScreen'));

      await driver.tap(find.text('川菜'));

## ⚡ 性能测试

### 性能指标测试
```dart
// test/performance/performance_test.dart
import 'package:flutter_test/flutter_test.dart';
import 'package:flutter/services.dart';

void main() {
  group('Performance Tests', () {
    testWidgets('bubble animation performance', (tester) async {
      // 设置性能监控
      await tester.binding.setSurfaceSize(Size(800, 600));
      
      // 创建大量气泡
      await tester.pumpWidget(
        MaterialApp(
          home: BubbleScreen(bubbleCount: 50),
        ),
      );
      
      // 测试动画性能
      final stopwatch = Stopwatch()..start();
      
      for (int i = 0; i < 60; i++) {
        await tester.pump(Duration(milliseconds: 16)); // 60 FPS
      }
      
      stopwatch.stop();
      
      // 验证性能指标
      expect(stopwatch.elapsedMilliseconds, lessThan(1100)); // 允许10%误差
    });
    
    testWidgets('memory usage test', (tester) async {
      // 模拟内存使用测试
      final initialMemory = await getMemoryUsage();
      
      // 创建和销毁多个页面
      for (int i = 0; i < 10; i++) {
        await tester.pumpWidget(MaterialApp(home: RecommendationScreen()));
        await tester.pumpWidget(Container());
      }
      
      final finalMemory = await getMemoryUsage();
      
      // 验证内存没有显著增长
      expect(finalMemory - initialMemory, lessThan(10 * 1024 * 1024)); // 10MB
    });
  });
}
```

// test/security/security_test.dart
void main() {
  group('Security Tests', () {
    test('password hashing', () {
      final password = 'testPassword123';
      final salt = generateSalt();
      
      final hashedPassword = hashPassword(password, salt);
      
      // 验证密码不以明文存储
      expect(hashedPassword, isNot(password));
      expect(hashedPassword.length, greaterThan(32));
    });
    
    test('data encryption', () {
      final sensitive = 'sensitive user data';
      final key = generateEncryptionKey();
      
      final encrypted = encrypt(sensitive, key);
      final decrypted = decrypt(encrypted, key);
      
      // 验证加密/解密正确性
      expect(encrypted, isNot(sensitive));
      expect(decrypted, equals(sensitive));
    });
    
    test('input validation', () {
      final validator = InputValidator();
      
      // 测试SQL注入防护
      expect(validator.isValidInput("'; DROP TABLE users; --"), false);
      
      // 测试XSS防护
      expect(validator.isValidInput('<script>alert("xss")</script>'), false);
      
      // 测试正常输入
      expect(validator.isValidInput('正常的食物名称'), true);
    });
  });
}

## 🐛 缺陷管理

### 缺陷分类
- **P0-紧急**: 影响核心功能，需立即修复
- **P1-高**: 影响用户体验，需尽快修复
- **P2-中**: 一般问题，可计划修复
- **P3-低**: 优化建议，可选择性修复

### 已知问题
1. **P1**: 集成测试中某些动画测试不稳定
2. **P2**: 性能测试在低端设备上可能超时
3. **P3**: 某些UI测试在暗色主题下断言失败

### 缺陷跟踪流程
1. **发现** → 在测试中识别问题
2. **记录** → 详细记录复现步骤
3. **分类** → 根据严重程度分类
4. **分配** → 分配给相应开发人员
5. **修复** → 编码解决问题
6. **验证** → 重新测试确认修复
7. **关闭** → 确认问题解决
