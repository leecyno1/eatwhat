# EatWhat 2.0 - 需求分析文档 (Requirement Analysis)

## 1. 项目愿景 (Vision)
打造一款基于 AI 深度驱动的智能饮食决策与执行平台。不仅仅是"随机吃什么"，而是通过深度学习用户偏好，提供从"灵感启发"到"决策辅助"再到"执行落地"的全链路服务。

## 2. 核心功能模块 (Core Modules)

### 2.1 智能偏好气泡 (Smart Preference Bubbles)
- **功能**: 用户启动 App 时的首屏交互。
- **数据源**: 100+ 个底层偏好元素（菜系、口味、食材、营养、场景、占卜、个人信息）。
- **算法**:
  - **随机性**: 每次启动随机展示不同组合。
  - **学习性**: 根据历史点击率进行正向/逆向偏移（喜欢的出现频率高，不喜欢的减少）。
- **视觉 (Visualization)**:
  - **实体化**: 每个标签对应一个独特的视觉实体（Entity）。
  - **形状**: 结合文字形状（如"辣"字变形为辣椒轮廓）。
  - **意境**: 配合背景色和光影。
  - **动画**: 动态效果（如蒸汽、火焰、水滴）。
  - **数量**: 至少 100 个独特的视觉设计。

### 2.2 智能决策引擎 (AI Decision Engine)
- **交互**: 用户选中气泡 -> 确认 -> 老虎机滚动动画 -> AI 推理。
- **输入**: 用户选中的标签组合 + 用户画像（历史偏好、忌口）。
- **处理**: 调用 LLM (SiliconFlow/Qwen) 进行深度推理。
- **输出**: 推荐目标菜品列表（通常 1-3 个最佳匹配）。
- **生成能力**:
  - **菜品图**: 调用 AI 绘图 API 生成精美菜品图。
  - **搭配推荐**: 自动生成搭配的饮品、配菜、主食，以气泡形式悬浮在结果旁，可一键添加。

### 2.3 全链路执行系统 (Execution System)
用户选定菜品后，提供三种执行路径：

#### A. 自制 (Home Cooking)
- **数据源**: 完备的本地/云端菜谱数据库 (Unified Recipe Database)。
- **内容**:
  - 详细步骤（图文/视频）。
  - 精确配料表。
  - 营养分析（AI 生成）。
  - 烹饪计时器。

#### B. 到店 (Dine-in)
- **数据源**: 餐厅 API (大众点评/美团等 Mock)。
- **内容**:
  - 附近推荐餐厅列表。
  - 餐厅评分、人均价格。
  - 导航链接。

#### C. 外卖 (Delivery)
- **数据源**: 外卖 API (美团/饿了么 Mock)。
- **内容**:
  - 附近外卖店列表。
  - 直达下单链接。

### 2.4 收藏与个性化 (Favorites & Personalization)
- **全流程收藏**:
  - 收藏偏好标签（气泡）。
  - 收藏菜谱。
  - 收藏餐厅/外卖店。
- **影响机制**: 收藏的内容在后续推荐中权重极大增加。

## 3. 技术架构升级 (Architecture Upgrade)

### 3.1 数据库层
- **Unified Recipe Schema**: 统一 HowToCook 和下厨房数据结构。
- **Local DB**: 使用 `Hive` 或 `Isar` 存储用户偏好、收藏、历史记录。

### 3.2 AI 服务层
- **LLM**: 继续使用 SiliconFlow，优化 Prompt 以支持结构化输出（JSON）。
- **Image Gen**: 接入 Text-to-Image API (e.g., Stable Diffusion via API)。

### 3.3 UI 表现层
- **Flame Engine**: 继续用于气泡物理系统，但需深度定制 `BodyComponent` 以支持复杂动画。
- **Custom Painters**: 为 100+ 个实体绘制独特的视觉效果。

## 4. 开发阶段规划 (Phases)

### Phase 1: 基础数据与视觉重构 (Current)
- 建立 Unified Recipe Database。
- 实现 100+ 个偏好实体的视觉设计系统 (Visual Entity System)。
- 升级气泡游戏引擎。

### Phase 2: AI 深度集成
- 接入 AI 绘图。
- 优化推荐算法（引入用户画像权重）。
- 实现搭配推荐逻辑。

### Phase 3: 执行路径实现
- 开发自制菜谱详情页（含营养分析）。
- 开发餐厅/外卖推荐页（Mock 数据 + 地图集成）。

### Phase 4: 收藏与闭环
- 实现全链路收藏功能。
- 完善用户偏好学习算法。
