《吃什么》是一款帮你决定“今天吃什么”的饮食推荐应用：点选口味气泡、摇一摇翻锅，得到懂你时段与近况的菜品推荐；也可以从冰箱现有的食材反查能做的菜。

常见问题

需要注册才能用吗？

不需要。推荐、菜谱浏览、冰箱找菜与一周饮食报告都可以直接体验。登录后可以保留账号身份与会员状态。

为什么外卖下单显示“服务尚未开通”？

外卖下单依赖美团开放平台的应用资质审批。审批通过前，该入口保持关闭，不影响做菜与到店路径，也不会发生真实下单或扣款。

会员在哪里购买？

移动端不提供应用内数字商品购买入口。会员购买目前仅在 Web 端通过支付宝官方渠道完成；移动端可查看已有会员状态。

如何注销账号？

进入首页右上角账号入口，在账号面板底部点击「注销账号」，输入密码确认即可。详细说明见《账号注销说明》。

定位、麦克风什么时候使用？

只有在你主动搜索附近门店时才会请求定位；只有长按语音输入时才会使用麦克风与系统语音识别。拒绝授权不影响核心推荐流程。

数据存在哪里？

账号、口味偏好、收藏与饮食记录仅保存在你的设备上，不提供云端同步。详见《隐私政策》。
