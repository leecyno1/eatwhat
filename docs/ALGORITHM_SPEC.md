# 偏好学习与推荐算法说明

目标：用最少交互快速收敛用户“当下口味-心情”向量，输出多样性候选美食集合，并支持持续在线更新。

## 1. 特征与画像
- 口味轴：辣/麻/甜/酸/咸/鲜/苦/油腻-清淡/重口-清爽/香料感等（0–1 标准化）。
- 心情与情境：解压/清淡/高能/社交；时间（早/午/晚/夜宵）、天气、地点（家/公司/商圈）。
- 食物画像：来自食谱/标签/食材 → 映射到口味轴 + 烹饪法（炸/烤/炒/蒸）。

## 2. 成对偏好学习（在线）
- 交互：对口味气泡/菜品的上滑(1)/下滑(0)作为偏好对，构造 (x, y)。
- 模型：Logistic 回归或 Bradley–Terry（对比）在线更新；参数 w 初始化来自首启问卷与通用先验：
  - 似然：p(y=1|x)=σ(w·x)；梯度：w←w+η·(y-σ)·x；小批量/动量可选。
  - 对 BT：每个口味/菜品一个强度参数，成对比较更新。
- 约束：L2 正则 + 边界裁剪，防止极端权重；衰减过去权重以追踪“当下”。

## 3. 候选生成与排序
1) 候选集召回：
   - FTS：按口味/菜名/标签检索（SQLite FTS5）；
   - 规则召回：饮食禁忌/预算/时长/器具硬过滤；
   - 多样性：基于口味轴最大化覆盖，防止同质化。
2) 打分：score = α·(w·x_food) + β·context + γ·novelty - δ·冲突惩罚。
3) 探索：ε-greedy（ε=0.1 起），或汤普森采样近似；保证发现新偏好。

## 4. 评价与回传
- 在线指标：决策时间↓、放弃率↓、选择后满意度↑、二跳行为（菜谱/外卖/附近）。
- 离线回放：用历史滑动序列重放，评估 Top-K 成功率与多样性。

## 5. 数据与持久化
- 偏好参数：Hive（会话级/用户级）；
- 食谱/标签：SQLite（结构化 + FTS 索引）。

参考：Bradley–Terry、Pairwise Preference Learning、Just Sort It! (active preference)。
