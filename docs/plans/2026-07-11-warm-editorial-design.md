# 「暖食编辑部」正式视觉设计

## 产品气质

正式主视觉采用方案 A「暖食编辑部」：温暖、克制、真实、有食欲。产品不再依赖玻璃拟态、气泡物理、卡牌纹理或持续漂浮动画制造吸引力，而是把真实菜品摄影、清晰的口味表达和明确的行动按钮放在第一层。用户打开应用后，应当在数秒内完成“表达胃口 → 收窄选择 → 确认菜品 → 选择执行方式”。

品牌记忆点由三部分组成：暖米色纸张感背景、辣椒红行动色、宋体标题与真实菜品大图。页面只保留极轻的圆环和细线装饰，不使用大面积渐变、透明叠层或无意义动态光斑。标题负责情绪，正文负责信息，红色只用于当前选择和主要行动。

## 页面结构

首页改为单一纵向决策流：品牌与场景信息、主标题、口味标签、当前菜品预览、自由输入与生成按钮。口味标签支持点击喜欢、长按排除；时间、预算、人数和执行方式作为快速条件，不再藏在复杂卡牌交互中。推荐生成页用三个清楚阶段表达进度，不再模拟老虎机。结果页、详情页和执行页继续复用现有控制器与服务，只统一背景、字体、容器和行动色。

## 技术原则

- 保留现有推荐、偏好学习、图片、营养、收藏、外卖与堂食服务。
- 新建正式首页，旧九宫格首页暂时保留，便于回归和逐步迁移。
- 路由默认进入新首页；旧组件测试不删除。
- 视觉通过统一 token 和静态背景向结果、详情、执行页面传播。
- 网络、语音、数据库或平台能力失败时，页面仍可使用本地标签、文字输入和本地推荐。

## 验收标准

- 375×812 与窄屏设备无溢出。
- 首页无需学习手势即可完成一次推荐。
- 动画关闭后不影响任何功能或信息理解。
- 主要文字对比度、触控区域和状态反馈满足移动端可用性要求。
- 推荐、收藏、历史、做菜、外卖和堂食入口继续可达。
