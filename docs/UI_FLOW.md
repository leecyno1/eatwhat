# 关键界面与交互

1. 首次设置（Onboarding）
- 选择禁忌/过敏、口味初始值、预算、做饭/外卖偏好、常用器具；
- 定位授权（用于“附近餐馆”）。

2. 气泡偏好页（核心）
- 大/中/小多层气泡（口味/心情/烹饪法）；
- 上滑=喜欢、下滑=不喜欢、左右=跳过/探索、双击=锁定、长按=示例菜；
- 顶部进度与“立即推荐”CTA；
- 触感反馈、阻尼动画、撤销按钮。

3. 候选美食页
- 5–9 卡片，显示图、标签、时长、价格、热量估算；
- 操作：菜谱、外卖、附近；
- “换一批”保留 30% 多样性探索。

4. 菜谱详情
- 步骤、食材替代、器具、视频（可选），一键加入购物清单。

5. 附近餐馆
- 拉起 Apple 地图或内嵌列表，按口味/菜名搜索；
- 导航与电话/订座。
